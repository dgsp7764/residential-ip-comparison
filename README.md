## 先搞清楚一件事：住宅IP到底是什么

**住宅IP（Residential IP）**，指的是由电信运营商（ISP）分配给真实家庭用户的宽带地址。当你用这类IP访问网站时，对方看到的是一个正在用家庭网络上网的普通人，而不是某个机房服务器。

这和机房IP（Datacenter IP）的区别，不是几个百分点的差距，是本质上的不同。

机房IP的ASN归属是已知的托管服务商，像AWS、Vultr、DigitalOcean这些，TikTok、Google、美国银行这类平台早就把这些IP段标了颜色。一旦检测到你用的是机房IP，轻则要求短信验证，重则直接封号。

住宅IP则不一样。它的网络特征和普通用户一模一样，ASN显示的是AT&T、Comcast、Spectrum这类家庭宽带运营商。平台的风控系统即便再严，也很难把它和真实用户区分开。

简单说：**住宅IP是给需要"假装成本地人"的业务用的，机房IP是给不在乎被识别出来的场景用的。**

## 住宅IP对比：静态 vs 动态，哪种适合你？

做住宅IP对比之前，先要分清楚静态和动态两种类型，因为用错了同样白搭。

**动态住宅IP（Rotating Residential Proxy）**：IP地址会自动轮换，每次请求可能用不同的IP。适合大规模数据采集、爬虫类需求。缺点是IP不固定，账号类业务（比如TikTok账号运营、社媒养号）用动态IP很容易因为IP频繁变动被平台判定为异常行为。

**静态住宅IP（Static Residential IP / ISP Proxy）**：IP地址长期固定，来自真实家庭宽带线路。适合需要长期维持稳定登录状态的场景——TikTok直播、跨境电商账号管理、美区流媒体、金融平台访问等。
